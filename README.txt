Summary--------------------------------------------

Home: Gives quick access to portal links and tools. 

Course Search: Allows users to view all courses as a list or search them by their name or code.

Student Registration: Allows students to select their profile and choose courses to add/drop. It also shows currently enrolled courses and any conflicts. 

Instructor Schedule: Shows a professor's teaching schedule when they select their profile. 

Session Enrollment: Tool to view class members by course.


Techniques -----------------------------------------

This dashboard utilizes CSS FlexBox and Grid to allow for dynamic resizing of content. It also utilizes JavaScript to dynamically show and hide content instead of pulling multiple HTML pages. All content refreshes dynamically through JS.

Decisions+Challenges -------------------------------

I had to redo my flex grid because content was overlapping or wasn't justifying properly. I also used a couple of templates online to polish the look and feel of the site. Keeping the layout simple also makes it modular, so future changes can be easily implemented.
